Première version

IntroMux est un petit logiciel Windows gratuit pour préparer des vidéos en série : il colle une intro au début de chaque vidéo, ajoute les sous-titres de cette vidéo (uniquement sur la vidéo, jamais sur l'intro) et encode tout à la chaîne, pendant que vous faites autre chose.

Il sait aussi faire ce que fait Avidemux : regarder la vidéo, la couper avec des repères A/B, choisir le format, la qualité, la résolution, les filtres d'image…

Ce que fait IntroMux

  • Intro : une vidéo (générique, logo, jingle…) placée avant la vidéo principale. Facultatif : une outro à la fin.
  • Sous-titres sur la vidéo principale seulement : fichiers .ass, .ssa, .srt, .vtt, ou piste de sous-titres déjà présente dans la vidéo (MKV). Leur minutage reste celui de la vidéo : le « 00:00 » des sous-titres correspond au début de l'épisode, pas au début de l'intro. Ils n'apparaissent donc jamais pendant l'intro.
  • File d'attente : intro + épisode 1 + sous-titres 1, intro + épisode 2 + sous-titres 2… autant que vous voulez. IntroMux les encode l'une après l'autre, tout seul.
  • Dossier et nom de chaque fichier choisis avant l'export (avec un modèle automatique, par exemple Episode 01_final.mp4).
  • Arrière-plan : IntroMux continue dans la zone de notification (près de l'horloge), empêche la mise en veille pendant l'encodage et vous prévient quand c'est fini.
  • Ressources maîtrisées : priorité basse, limite d'utilisation du processeur, nombre de cœurs… pour continuer à utiliser le PC normalement.
  • Carte graphique détectée automatiquement (NVIDIA, Intel ou AMD) pour encoder vite ; sinon le processeur prend le relais.

Prise en main en 5 étapes

L'écran du haut est la composition d'une vidéo, de gauche à droite :

① INTRO   ➜   ② VIDÉO PRINCIPALE + SOUS-TITRES   ➜   ③ OUTRO (facultatif)
  1. L'intro — glissez votre vidéo d'intro dans la case ① INTRO (ou cliquez dessus pour la choisir). La case à cocher Garder, cochée d'office, la laisse en place pour toutes les vidéos suivantes : vous ne la choisissez qu'une fois. N'y touchez pas ; décochez-la seulement si cette intro ne doit servir qu'à la vidéo en cours (elle est alors retirée après l'ajout à la file d'attente).
  2. La vidéo principale — glissez l'épisode dans la case ② VIDÉO PRINCIPALE. L'aperçu s'affiche à droite. Si un fichier de sous-titres porte le même nom que la vidéo (par exemple Episode 01.fr.ass à côté de Episode 01.mkv), il est trouvé automatiquement.
  3. Les sous-titres — sinon, glissez le fichier .ass / .srt sur l'encadré SOUS-TITRES (ou sur la vidéo principale), ou cliquez sur Parcourir… dans l'encadré SOUS-TITRES (Ctrl+T). Choisissez : - Incrustés : dessinés dans l'image, toujours visibles, lisibles partout ; - Piste séparée : le spectateur peut les activer ou non dans son lecteur.
  4. La sortie — par défaut, la vidéo finale est enregistrée à côté de l'épisode (case « Même dossier que la vidéo » cochée). Pour l'enregistrer ailleurs, cliquez sur Parcourir… à côté du champ Dossier : la case « Même dossier que la vidéo » se décoche toute seule, et ce dossier est retenu pour les vidéos suivantes, même après un redémarrage (réglage par défaut : Outils → Paramètres → Général → Dossier de sortie). Vérifiez ensuite le nom du fichier (proposé automatiquement, modifiable) et le profil (« Standard » convient presque toujours).
  5. Ajouter à la file d'attente (Ctrl+Entrée). Recommencez pour l'épisode suivant (l'intro est déjà en place), puis cliquez sur Démarrer (F5) : l'encodage commence à ce moment-là.

Astuces :

  • Ajouter plusieurs vidéos… (Ctrl+Maj+O) : sélectionnez tous les épisodes d'un coup ; IntroMux associe chaque vidéo à ses sous-titres par le nom et vous laisse corriger les noms de sortie avant de tout ajouter.
  • Couper : placez les repères A et B (touches [ et ]), puis Supprimer A→B (enlève le passage) ou Garder A→B (ne garde que ce morceau).
  • Aperçu final : montre une image telle qu'elle sera encodée (sous-titres compris). Extrait de test : encode 10 secondes pour vérifier le résultat avant de lancer la file.
  • Message « Aperçu indisponible pour ce format » : seul l'aperçu ne sait pas lire ce fichier, l'encodage fonctionnera quand même.

Raccourcis utiles :

Touche Action
Espace lecture / pause de l'aperçu

Maj+← / Maj+→ ± 1 seconde

La file d'attente

La partie basse de la fenêtre liste les vidéos à produire, avec leur progression, la vitesse et le temps restant.

  • Les tâches sont encodées dans l'ordre, l'une après l'autre. Une tâche ajoutée pendant l'encodage est prise en compte automatiquement.
  • Pause / Reprendre (F6) met l'encodage en pause sans rien perdre ; Arrêter (F7) interrompt et remet les tâches « En attente » ; Arrêter après la tâche en cours termine proprement la vidéo en cours puis s'arrête.
  • ▲ ▼ ou glisser-déposer pour changer l'ordre ; double-clic sur une tâche en attente pour la modifier ; Dupliquer, Relancer (après une erreur), Supprimer.
  • Le nom de sortie se modifie directement dans la liste (tant que la tâche n'a pas commencé).
  • Si un fichier du même nom existe déjà, IntroMux ajoute « (2) », « (3) »… (réglable : écraser ou ignorer). Il n'écrase jamais une de vos vidéos sources.
  • À la fin : ne rien faire, mettre en veille, éteindre le PC ou quitter IntroMux (avec un compte à rebours de 60 secondes que vous pouvez annuler).
  • La file est enregistrée automatiquement : si vous fermez IntroMux ou si le PC s'éteint, elle est toujours là au prochain lancement (la tâche interrompue repart du début).
  • Fichier → Exporter la file… / Importer une file… pour la sauvegarder ou la reprendre sur un autre PC.

Travailler en arrière-plan

  • Fermer la fenêtre (✕) n'arrête pas IntroMux : il se range dans la zone de notification, près de l'horloge (parfois cachée derrière la petite flèche ^).
  • Clic sur l'icône : réafficher la fenêtre. Clic droit : démarrer, pause, arrêter après la tâche en cours, quitter. Une notification s'affiche à la fin de chaque vidéo (si les notifications de Windows sont activées ; sinon l'icône IntroMux affiche ✓ ou ! et une petite fenêtre résume la file à la fin).
  • Pendant l'encodage, le PC ne se met pas en veille (réglable).
  • Pour quitter vraiment : Fichier → Quitter (Ctrl+Q) ou clic droit sur l'icône → Quitter.
  • Options (Outils → Paramètres → Comportement) : lancer IntroMux au démarrage de Windows, démarrer réduit, reprendre la file au lancement.

Ressources : garder un PC fluide

Outils → Ressources… :

  • Priorité : « Basse » (recommandée) laisse la priorité à ce que vous faites ; l'encodage utilise le reste du processeur. « Très basse » : seulement quand le PC ne fait rien.
  • Limite processeur (%) : plafond strict, par exemple 50 % pour garder un PC silencieux et frais. 100 % = pas de limite.
  • Cœurs et threads : réserver une partie des cœurs du processeur à IntroMux.
  • Carte graphique : choix de la carte NVIDIA à utiliser, décodage matériel, et retour automatique au processeur si la carte graphique échoue.
  • Encodages simultanés : 1 par défaut (strictement l'une après l'autre). 2 ou plus peut aller plus vite sur un gros processeur ; les cartes GeForce limitent toutefois le nombre d'encodages simultanés.

La priorité, les cœurs et la limite processeur s'appliquent immédiatement, même aux encodages en cours.

Profils d'encodage

Un profil regroupe tous les réglages d'encodage. Profils fournis :

Profil Pour quoi faire
Standard — H.264 (GPU auto) le bon choix par défaut : lisible partout (téléphone, TV, navigateur)
Haute qualité — H.264 x264 (processeur) image très propre, plus lent, fichiers plus gros
Rapide — NVIDIA NVENC H.264 très rapide sur carte NVIDIA (sinon le processeur prend le relais)
Compact — H.265/HEVC (GPU auto) fichiers deux fois plus petits, pour appareils récents
Anime — HEVC 10 bits x265 (lent, très propre) animation : dégradés sans escaliers, fichier MKV
Moderne — AV1 (GPU auto) fichiers très compacts ; rapide seulement sur cartes récentes
YouTube 1080p prêt à mettre en ligne en 1920×1080
Partage léger — 720p (≈ 50 Mo) à envoyer par messagerie (vidéos de moins de 10 minutes)
Copie rapide (coupe sans ré-encodage) couper sans perte, instantané (sans intro ni sous-titres incrustés)

Profils → Gérer les profils… (Ctrl+P) : dupliquez un profil fourni pour le modifier (codec, qualité, résolution, recadrage, débruitage, transition intro→vidéo, son, style des sous-titres .srt…). Exporter… / Importer… permet d'échanger des profils avec vos amis.

En cas de problème

Les journaux

Outils → Ouvrir le dossier des journaux (c'est %APPDATA%\IntroMux\logs) :

  • app.log : le journal du programme ;
  • job_….log : un fichier par vidéo encodée, avec la commande ffmpeg exacte et ses messages.

Pour demander de l'aide, envoyez ces fichiers (et une capture du message d'erreur).

Tester l'installation

Outils → Tester l'installation crée deux petites vidéos de test, les encode avec la file d'attente (processeur, puis carte graphique si elle est disponible), puis vérifie la durée, l'image, le son et les sous-titres. Tout se passe dans un dossier temporaire : vos réglages et votre file ne sont pas touchés.

En ligne de commande (même test, sans fenêtre) :

start /wait IntroMux.exe --selftest --selftest-out "%USERPROFILE%\Desktop\rapport-intromux.json"
  • start /wait attend la fin du test (IntroMux est un programme à fenêtre : sans cela, la commande rend la main tout de suite) ;
  • sans --selftest-out, le rapport est écrit dans %APPDATA%\IntroMux\logs\selftest-report.json ;
  • --no-gpu teste seulement le processeur ;
  • code de retour 0 = tout va bien, 1 = au moins une étape a échoué (le rapport dit laquelle).

Problèmes fréquents

  • « L'encodeur de la carte graphique a échoué » : mettez à jour le pilote de la carte graphique. Si le retour au processeur est activé (par défaut), la vidéo est quand même encodée, plus lentement.
  • « Disque plein » : libérez de la place sur le disque de sortie, ou choisissez un autre dossier temporaire (Outils → Paramètres → Général).
  • « Accès refusé » : le dossier de sortie est protégé, ou le fichier est ouvert dans un lecteur vidéo : fermez-le ou choisissez un autre dossier.
  • « Erreur de lecture ou d'écriture sur un disque » : la clé USB, le disque externe ou le disque réseau a été débranché ou déconnecté pendant l'encodage. Rebranchez-le, puis Relancer la tâche.
  • « Windows a refusé de créer le fichier de sortie » : le nom ou le chemin du fichier est refusé (trop long, ou dossier inaccessible). Raccourcissez le nom ou choisissez un autre dossier. Avec l'avertissement « Chemin de sortie très long », IntroMux enregistre bien la vidéo, mais l'Explorateur et beaucoup de lecteurs ne pourront pas l'ouvrir : préférez un dossier moins profond.
  • Des « Ã© » à la place des « é » dans les sous-titres : « Ã© » est un « é » enregistré en UTF-8 (l'encodage moderne) mais lu comme un fichier ancien (Windows-1252). Cela arrive quand un fichier UTF-8 contient aussi quelques caractères d'un ancien encodage, souvent une apostrophe ou des guillemets collés depuis Word. IntroMux répare ces fichiers tout seul et le signale (« Quelques caractères mal encodés du fichier de sous-titres ont été corrigés »). Si des « Ã© » restent visibles dans l'aperçu, choisissez UTF-8 (forcé…) dans Outils → Paramètres → Général → Encodage des .srt anciens. S'ils restent encore, ils sont écrits tels quels dans le fichier : il faut récupérer un fichier de sous-titres propre. Pour réparer vous-même un fichier mélangé (utile pour d'autres lecteurs) : dans le Bloc-notes, Fichier → Ouvrir…, choisissez UTF-8 dans la liste Encodage en bas de la fenêtre, ouvrez le fichier, remplacez les quelques « � » par le bon caractère, puis Fichier → Enregistrer.
  • D'autres caractères bizarres dans un vieux .srt (lettres accentuées sans rapport avec le texte, par exemple « Ïðèâåò » au lieu de russe) : le fichier n'est pas en UTF-8 ; choisissez son encodage dans Outils → Paramètres → Général → Encodage des .srt anciens (« Windows-1252 », le réglage par défaut, convient à la plupart des .srt français ; « Windows-1251 » pour le russe…).
  • File d'attente vide au démarrage, avec un message « illisible » : le fichier de la file (queue.json) était abîmé. IntroMux l'a mis de côté sous le nom queue.json.corrupt-… (dans %APPDATA%\IntroMux) et repart avec une file vide. Vous pouvez essayer de le réimporter : Fichier → Importer une file…, choisissez « Tous les fichiers » puis ce fichier.
  • Réglages abîmés : IntroMux met de côté un fichier de réglages illisible (settings.json.corrupt-…) et repart des réglages par défaut. Pour tout remettre à zéro, quittez IntroMux et supprimez le dossier %APPDATA%\IntroMux.
  • « IntroMux ne peut pas démarrer : son dossier est rangé trop profondément » (version portable) : déplacez le dossier IntroMux plus près de la racine du disque, par exemple dans C:\IntroMux.
