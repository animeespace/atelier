Guide d'utilisation

Tout ce qu'il faut savoir pour installer Atelier, tes logiciels et leurs mises à jour.

Configuration requise

  • Windows 10 ou 11, 64 bits. Pas de Mac ni de Linux.
  • Une connexion Internet pour installer les logiciels et recevoir les mises à jour. Une fois installés, ils fonctionnent sans connexion.
  • De la place sur le disque : environ 70 Mo pour Atelier, plus celle des logiciels choisis :
    • IntroMux : 312 Mo, dont 120 Mo à télécharger
    • Retime : 4,7 Go, dont 2,9 Go à télécharger
    • SubExtract : 548 Mo, dont 225 Mo à télécharger
  • Aucun droit administrateur : tout s'installe dans ton dossier utilisateur.

Installer Atelier

  1. Télécharge Atelier-Setup.exe (21 Mo). Si ton navigateur prévient que ce fichier « n'est pas couramment téléchargé », choisis Conserver (dans Edge : menu … du téléchargement → Conserver, puis Conserver quand même).
  2. Ouvre le fichier depuis tes téléchargements.
  3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. C'est normal : Atelier n'est pas signé par un éditeur payant. Windows ne le demande qu'une fois.
  4. Laisse cochée (ou non) la case du raccourci sur le Bureau, clique sur Installer, puis sur Terminer.

Atelier s'ouvre tout seul. Il est aussi dans le menu Démarrer. Il démarre désormais avec Windows, discrètement, près de l'horloge : c'est ce qui lui permet d'installer les mises à jour sans que tu y penses.

Installer un logiciel

Dans Applications, chaque logiciel a sa carte. Clique sur Installer : la carte affiche le téléchargement (taille et vitesse), puis l'installation. Le bouton ✕ l'annule.

Une fois installé, le logiciel passe dans la partie Installé sur cette machine et apparaît dans le menu Démarrer (et sur le Bureau, si ce réglage est activé). Les filtres en haut (catégories) et la barre de recherche aident à s'y retrouver quand il y en a beaucoup.

Astuce : les logiciels vont dans %LOCALAPPDATA%\Atelier\Apps. Pour les mettre sur un autre disque (Retime est gros), change le dossier dans Paramètres avant de les installer.

Si le téléchargement est coupé (connexion perdue, PC éteint), relance-le : il reprend là où il s'était arrêté.

Ouvrir un logiciel

  • le bouton Ouvrir de sa carte dans Atelier ;
  • le menu Démarrer, ou son raccourci sur le Bureau ;
  • clic droit sur l'icône de Atelier près de l'horloge → Lancer ….

Tu peux aussi l'épingler à la barre des tâches : l'épingle reste valable après les mises à jour.

Les mises à jour

Atelier vérifie s'il y a du nouveau à chaque démarrage, puis toutes les heures. Par défaut, il installe les mises à jour tout seul, en arrière-plan, et te prévient par une notification.

  • Une pastille bleue sur Mises à jour signale qu'une nouvelle version est disponible. Cette page montre ce qui change, la taille à télécharger (souvent quelques Mo seulement) et un bouton Mettre à jour.
  • Rechercher (ou l'icône ↻ en haut à droite) vérifie tout de suite, sans attendre l'heure suivante.
  • Si un logiciel est ouvert, sa mise à jour est préparée à côté et sa carte indique « prête : ferme le logiciel ». Elle est appliquée dès que tu le fermes, y compris s'il était réduit près de l'horloge (comme IntroMux).
  • Atelier se met aussi à jour lui-même : il se ferme et se rouvre en quelques secondes.

Pour choisir toi-même quand mettre à jour, coupe Mises à jour automatiques sur la page Mises à jour : tu recevras une notification à chaque nouvelle version.

Réparer ou désinstaller un logiciel

Le menu … en haut à droite de chaque carte propose :

  • Détails et nouveautés : la description et l'historique des versions ;
  • Ouvrir le dossier d'installation ;
  • Créer un raccourci sur le Bureau ;
  • Réparer (tout retélécharger) : si le logiciel ne démarre plus, par exemple après le passage d'un antivirus ;
  • Désinstaller : supprime le logiciel. Ses réglages et tes fichiers de travail sont conservés, tu les retrouveras si tu le réinstalles.

Quitter ou désinstaller Atelier

Quitter : clic droit sur l'icône de Atelier près de l'horloge → Quitter (la croix de la fenêtre ne fait que la réduire).

Désinstaller : Paramètres de Windows → Applications → Atelier → Désinstaller. Le désinstalleur demande s'il faut aussi supprimer les logiciels installés.

En cas de problème

« Hors ligne » ou « Impossible de récupérer la liste des logiciels »

Vérifie ta connexion, puis clique sur Réessayer. Les logiciels déjà installés fonctionnent sans connexion.

Mon antivirus a bloqué ou supprimé un fichier

C'est un faux positif fréquent avec ce genre de programme. Restaure le fichier depuis la quarantaine, ajoute une exception pour le dossier %LOCALAPPDATA%\Atelier, puis utilise Réparer dans le menu … du logiciel.

« Espace disque insuffisant »

Libère de la place, ou choisis un autre disque dans Paramètres → Dossier d'installation, puis réessaie.

Une mise à jour reste « prête » sans s'appliquer

Le logiciel tourne encore, peut-être réduit près de l'horloge. Quitte-le complètement : la mise à jour s'applique dans les secondes qui suivent.

« Dossier d'installation introuvable »

Le dossier du logiciel a été déplacé ou supprimé. Clique sur Réinstaller sur sa carte.

Rien de tout ça

Envoie-moi le journal de Atelier : Paramètres → Ouvrir le dossier des journaux, fichier atelier.log. Pour un souci dans un logiciel, regarde aussi sa page : IntroMux, Retime, SubExtract.
